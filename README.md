# OverGo

OverGo is an Android Pokémon assistant focused on building a private local collection from information the user explicitly shares from the screen.

> Independent fan project. Not affiliated with Niantic, The Pokémon Company, Nintendo, or Game Freak.

## MVP 0.1

Current branch: `feature/overgo-ai-mvp`

The first version contains:

- Android app written in Java.
- User-authorized screen capture with Android MediaProjection.
- Floating `SCAN` overlay.
- Local ML Kit OCR with the bundled Latin text model.
- Basic Pokémon name and CP/PC extraction from visible text.
- Local collection stored only in the app's private storage.
- A first local assistant that can answer questions using the scanned collection, such as collection count, most recent record, and highest CP/PC.

No Pokémon GO username, password, session token, private API, GPS spoofing, automated taps, or account automation is used.

## How to test

1. Install the APK generated by GitHub Actions.
2. Open OverGo.
3. Grant notification permission if Android asks.
4. Tap **Autorizar sobreposição** and allow OverGo to display over other apps.
5. Return to OverGo and tap **Iniciar scanner**.
6. Approve Android's screen-sharing dialog.
7. Open Pokémon GO and open a Pokémon's detail screen.
8. Tap the floating **SCAN** button.
9. Return to OverGo to see the locally saved collection and ask the assistant questions.

## Roadmap

1. Improve Pokémon name detection.
2. Detect appraisal bars for Attack / Defense / HP IVs.
3. Recognize appraisal stars and exact IV percentage.
4. Scan multiple Pokémon while the user moves through storage.
5. Add Pokémon species data, types, evolutions, moves, and counters.
6. Connect the local collection to a full Pokémon-focused language model through a secure backend.
7. Team builder using only Pokémon in the user's local collection.
8. PvP / raid recommendations based on the user's scanned Pokémon.

## Privacy model

Screen capture starts only after Android shows the system consent dialog. OCR runs on-device with the bundled ML Kit model. The current MVP does not upload screenshots or collection data.
